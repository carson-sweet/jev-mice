02 · Configure a run

Wireframe, not a mockup. Setting up a colony, the three checks that can stop a start, and the code-only twin. Covers F-03 and F-15. Neutral styling; no visual design has been chosen yet.

Configure a run — Defaults

F-03 steps 1 to 3 — FR-053, FR-055, FR-056, FR-140
  • Every setting from FR-053 is on one screen; Medium defaults from FR-055 are prefilled.
  • The estimate panel is FR-140 and is labelled as an estimate, with its basis stated.
  • Import and export of configuration plus seed is FR-056, and the same file round-trips.
  • Personality percentages state plainly that they apply to births as well as to the start (FR-043).

Configure a run — Validation error

F-03 step 2 — FR-054, FR-003
  • Errors appear beside the field, not in a summary at the top, and the run cannot start.
  • The message names the cap and the current total so the person can see what to change.
  • Caps derive from grid area, so changing the preset changes the message.

Configure a run — Budget too small

F-03 step 4 — FR-122
  • A run that would exceed the remaining budget is never refused outright.
  • Two ways forward are offered: run without the model, or shorten the run to what fits.
  • The shortened tick count is computed and shown, not left to the person to work out.
