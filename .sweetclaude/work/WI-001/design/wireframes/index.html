jev-mice wireframes

Nine screens covering all sixteen flows. Each file holds every state that screen can be in, switchable from the bar at the top. Two toggles in that bar: Notes shows which flows and requirements each state satisfies, Components outlines the regions that become React components. Neutral styling throughout; no visual design has been chosen yet.
